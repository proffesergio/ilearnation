## Scope and freshness

Node/React examples demonstrate isolated concepts, not full framework execution.
The GraphQL and realtime checkpoints simulate contracts without starting those
services. The MongoDB lessons teach document modeling and aggregation using arrays;
they do not change the platform's Neon/PostgreSQL backend. Framework extensions
should use their own pinned dependencies and current official guidance. No source
establishes a promise of employment, ranking, credential, or measured performance.

Check current documentation and the project's pinned versions before publishing
new commands. Preserve the 0.1.0 snapshot and issue a new course version for material
changes. Draft 0.2.0 remains subject to human curriculum, accessibility, and rights review.

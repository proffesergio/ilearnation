## Differences from the 2024 examples

Node24, React19, Next16, Express5, Mongoose9, Apollo4, and TanStack5 are pinned in
the project lockfile. Use that reviewed lock rather than assuming latest releases
are interchangeable. The SPA token is memory-only; passwords use salted scrypt;
JWT verification constrains algorithm/issuer/audience/expiry. Mongo event writes
use transactions on a replica set. The tiny GraphQL endpoint deliberately rejects
fragments and accepts one bounded operation. The SSR baseline uses renderToString,
safe JSON serialization, and hydrateRoot; it does not claim streaming/dehydration
is implemented. Offline writes are visibly refused, with bounded queueing taught
as an extension. The full project is separate from the platform's Neon account store.

# Research records

No external research has been performed in this bootstrap. Local runtime versions
and model-cache observations are environment evidence, not current-source research.

For each future primary source, record: title, author/publisher, URL, retrieval date,
supported claim, relevant chapter, and license/status. Label findings as fact,
recommendation, or experiment. An unvisited URL has no retrieval date. Do not infer
that public access grants permission to copy text or code.

Use dated kebab-case notes, such as `2026-10-16-course-schema-sources.md`.
Review source changes through local change sets or approved pull requests; published
course versions stay immutable. Reference inventory: ../../refBooks/references.json.
